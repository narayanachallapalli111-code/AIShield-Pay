# AIShield Pay

AIShield Pay is a production-inspired payment platform designed to demonstrate modern backend engineering practices. The project is built using Java and Spring Boot microservices with an event-driven architecture powered by Apache Kafka.

The platform focuses on secure payment processing, authentication, distributed transactions, caching with Redis, API Gateway, service discovery, centralized configuration, AI-powered capabilities using Spring AI, and Model Context Protocol (MCP) integration.

## Tech Stack

- Java 21
- Spring Boot
- Spring Cloud Gateway
- Spring Security (JWT)
- Eureka Server
- Spring Cloud Config
- PostgreSQL
- Redis
- Apache Kafka
- Docker
- Kubernetes
- Spring AI
- LangChain4j
- Model Context Protocol (MCP)
- React
- GitHub Actions
